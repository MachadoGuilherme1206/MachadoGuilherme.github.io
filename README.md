# 📋 Lista de Exercícios — HTML · CSS · JavaScript

**Seis aplicações web responsivas** que aplicam estrutura de decisão (`if` / `switch`),
comandos de repetição (`for` / `while`) e funções em JavaScript puro.

`HTML5` · `CSS3` · `JavaScript (Vanilla)` · sem frameworks · sem dependências

</div>

---

## ✨ Sobre

Página única com menu fixo, tema escuro e layout responsivo. Cada exercício tem um
**formulário** de entrada e um **painel de saída** que mostra os itens cadastrados e
um **relatório consolidado** gerado sob demanda. Todos os dados ficam em memória
(nenhum back-end).

## 🧩 Os exercícios

| # | Título | O que faz |
|:-:|--------|-----------|
| 01 | **Frete** | Frete por região, distância e quantidade de peças, com desconto no excedente acima de 1000 peças e relatório por região. |
| 02 | **Folha de pagamento** | Salário por categoria/turno, auxílio-alimentação por faixa e bônus por avaliação (0 a 10). |
| 03 | **Produção e estoque** | Custo ajustado por tipo de produto, alertas de estoque alto/crítico e consolidação por produto. |
| 04 | **Reservas de hotel** | Tarifa por tipo de quarto e temporada, café da manhã opcional e estatísticas de ocupação. |
| 05 | **Treinos esportivos** | Carga semanal por jogador, risco de sobrecarga e médias por tipo de treino e posição. |
| 06 | **Vendas e comissões** | Comissão base com bônus por cliente e região, controle de metas e performance por vendedor. |

## 🚀 Como rodar

Basta abrir o arquivo **`index.html`** no navegador.

## 📁 Estrutura

```
Lista1/
├── index.html      → estrutura e formulários dos 6 exercícios
├── style.css       → tema escuro, tokens e layout responsivo
├── script.js       → lógica dos exercícios + navegação
└── README.md
```

## 🎓 Conceitos aplicados

- **Estrutura de decisão** — `if / else if / else` e `switch`
- **Comandos de repetição** — `for` (percorrer listas) e `while` (validação de código único e de intensidade)
- **Funções** — cálculo isolado em funções puras (`calcularFrete`, `calcularReserva`, …) e utilitários reaproveitados (`moeda`, `avisar`, `painel`, …)
